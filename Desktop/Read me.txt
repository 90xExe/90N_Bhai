নিজের portfolio edit করার নিয়ম

সব personal information এখন Desktop folder-এ। GitHub-এ প্রয়োজনীয় file খুলে pencil/Edit চাপো, পরিবর্তন করে Commit changes দাও। Actions-এর deploy সফল হলে website refresh করো। কোনো পরিবর্তন দেখতে না পেলে একবার Ctrl + Shift + R চাপো।

কোথায় কী edit করবে:

About me/Profile.json — নাম, alias, পেশা, headline, stats, capability cards এবং ছবির path।
About me/Introduction.txt — প্রথম Welcome/About window-এর পরিচিতি। শুধু নিজের লেখা দাও।
About me/Bio.txt — About me-এর বিস্তারিত পরিচিতি। শুধু নিজের লেখা দাও।
About me/Profile.webp — তোমার ছবি। নতুন নামের ছবি দিলে Profile.json-এর photo path-ও বদলাও।
Experience/Experience.json — কাজের পদ, প্রতিষ্ঠান, সময় এবং description; items-এর একটি object কপি করে নতুন কাজ যোগ করো।
Skills/Skills.json — দক্ষতার groups ও items।
Contact/Contact.json — email, Facebook, YouTube, TikTok, Instagram এবং অন্য social links।
Assistant/Assistant.json — AI assistant-এর welcome, suggestions এবং custom প্রশ্ন-উত্তর।
Projects/ — নতুন project folder, ছবি, txt, PDF বা video এখানে যোগ করো। Thumbnails নিজে তৈরি হয়।

JSON edit করার সময় বাম দিকের field names, quotes, comma, [ ] ও { } ঠিক রাখবে; সাধারণত ডান দিকের লেখাগুলো বদলালেই হবে। Introduction.txt ও Bio.txt plain text, এখানে JSON লিখতে হবে না।

Assistant-এর {name}, {alias}, {email}, {social_links} নিজে থেকে Profile ও Contact-এর তথ্য ব্যবহার করে। একই তথ্য দুই জায়গায় লিখতে হয় না।

About me, Experience, Skills, Contact, Assistant folder এবং তাদের মূল JSON/TXT file-এর নাম একই রাখবে। Projects-এর ভিতরে নিজের মতো folder/file তৈরি করতে পারো।

Website-এর app খুললে সাজানো page দেখাবে। Show files in Finder চাপলে ওই app-এর source files দেখা যাবে। স্থায়ী পরিবর্তন GitHub-এর file editor বা নিজের computer-এর file-এ করতে হবে; visitor-এর browser থেকে GitHub file লেখা হয় না।

নিজের computer-এ Desktop edit করলে Refresh Desktop.cmd চালাও, অথবা Start Portfolio.cmd দিয়ে preview দেখো। Live website update করতে পরিবর্তন GitHub-এ commit/push করতে হবে।

File support: PNG, JPG/JPEG/JFIF, GIF, WebP, SVG, AVIF, BMP, ICO, TIFF, HEIC/HEIF images; PDF; video/audio; text/code; and all other downloadable files. TIFF and HEIC/HEIF get a PNG preview during deployment; originals remain downloadable. Animated GIF stays animated in Preview. Video/audio playback depends on browser codec support. ZIP, Office documents and unknown binary formats show file information and Download.

Assistant templates also support {role}, {bio}, {skills}, {experience}, {stats}; these follow the relevant personal files automatically.

Desktop-এর app ও folder icon চেপে ধরে drag করলে সরানো যাবে। এই browser-এ position save থাকবে; phone ও desktop-এর layout আলাদা। আগের অবস্থায় ফিরতে System Settings → Reset desktop layout চাপো। Keyboard দিয়ে icon-এ focus করে Alt + arrow keys ব্যবহার করো; Shift ধরলে বড় ধাপে সরবে। Drag করার সময় Esc চাপলে বাতিল হবে।
